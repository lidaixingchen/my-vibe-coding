## 使用方式

### 克隆仓库（含所有子模块）

```bash
git clone --recurse-submodules https://github.com/your-username/my-vibe-coding.git
```

### 添加子项目

```bash
git submodule add <仓库地址> <目录名>
```

### 更新所有子模块

```bash
git submodule update --remote
```
